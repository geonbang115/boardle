    5번의 시도 안에 오늘의 보드게임을 맞혀 보세요!

    게임 방법

    5번의 시도 안에 숨겨진 보드게임을 맞혀 보세요. 보드게임을 입력할 때마다 정답과의 속성 차이를 색상과 화살표로 알려줍니다.

    • 초록 정확히 일치 (난이도는 ±0.15 이내)
    • 노랑 근접 또는 일부 일치
    • 회색 일치하지 않음
    • ▲ / ▼ 정답의 값이 입력한 게임보다 높음(▲) 또는 낮음(▼)

    속성별 판정 기준

    • 출시 연도: ±3년 이내 노랑
    • 난이도: ±0.15 이내 초록, ±0.50 이내 노랑
    • 최소 / 최대 인원: ±1명 차이 노랑
    • 플레이 타임: 구간 겹침 또는 중간값 ±30분 이내 노랑
    • 메커니즘 / 테마: 2개 이상 일치 시 초록, 1개 일치 시 노랑 + 일치한 태그는 상단 단서 보드에 자동 누적

    힌트 시스템: 초성 1글자씩 공개, 디자이너 공개, 박스아트 중앙 1/9 공개, 원하는 속성 1개 정확히 공개를 사용할 수 있으며 사용한 힌트 수가 기록됩니다.
